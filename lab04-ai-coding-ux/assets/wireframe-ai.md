## 3. หน้า Add Product (เพิ่มสินค้าใหม่ - รองรับ 2 ชนิดสินค้า)
```text
+-------------------------------------------------------------+
| ENG-INVENTORY  [แดชบอร์ด]  [รายการสินค้า]  [เพิ่มสินค้า]  (สมชาย) |
+-------------------------------------------------------------+
|  เพิ่มรายการสินค้าใหม่ (Add New Product)                      |
|                                                             |
|  (*) ชนิดสินค้า (Product Type) *                            |
|  (o) สินค้าที่จับต้องได้ (Physical Goods - มีการตัดสต็อก)     |
|  ( ) สินค้าดิจิทัล/ไฟล์ (Digital Goods - ไม่มียอดคงเหลือ)    |
|                                                             |
|  ชื่อสินค้า (Product Name) *                                 |
|  [ สายไฟ THW 2.5 sq.mm                                    ] |
|                                                             |
|  รหัสสินค้า (Product Code / SKU) *                          |
|  [ ELEC-WIR-001                                           ] |
|                                                             |
|  หมวดหมู่สินค้า (Category) *                                 |
|  [ อุปกรณ์ไฟฟ้า / Electrical                            v ] |
|                                                             |
|  จำนวนสต็อกเริ่มต้น (Initial Quantity) *                     |
|  [ 50                                                     ] |
|                                                             |
|  ราคาต่อหน่วย (Unit Price - บาท) *                          |
|  [ 120.00                                                 ] |
|                                                             |
|  [v] บันทึกสำเร็จ: "เพิ่มสินค้า 'สายไฟ THW 2.5' เข้าระบบแล้ว" |
|                                                             |
|                                 [ ยกเลิก ]  [ + บันทึกสินค้า ]|
+-------------------------------------------------------------+
```
