# Persona: สมชาย มั่นคง

## ข้อมูลทั่วไป: 
- **อายุ:** 35 ปี
- **ตำแหน่ง:** เจ้าหน้าที่ดูแลคลังสินค้าและพัสดุ
- **ประสบการณ์:** 3 ปีในงานจัดการสต็อก
- **อุปกรณ์หลัก:** Desktop PC (Windows) ประจำคลัง + มือถือ Android ส่วนตัว
- **ทักษะเทคโนโลยี (1-5):** 2/5 (ใช้งาน Spreadsheet และโปรแกรมพื้นฐานได้ แต่ไม่คุ้นชินกับระบบที่ซับซ้อน)

## Quote ที่บ่งบอกตัวตน:
> *"กลัวพิมพ์ผิดช่อง หรือเผลอตัดสต็อกไฟล์ดิจิทัล แล้วต้องมานั่งไล่แก้ข้อมูลย้อนหลัง บางทีใช้เวลาเป็นวัน"*

## Goals:
1. บันทึกการรับเข้าและจ่ายออกสินค้าได้อย่างรวดเร็ว ไม่ต้องสลับหน้าจอไปมาหลายหน้าต่าง
2. ทราบสถานะสินค้าใกล้หมดสต็อกได้ทันทีผ่านหน้า Dashboard สรุปยอด

## Frustrations:
1. ฟอร์มกรอกข้อมูลไม่มีป้ายกำกับชัดเจน พอเริ่มพิมพ์แล้วจำไม่ได้ว่ากำลังกรอกข้อมูลอะไร
2. เคยเกิดปัญหาสต็อกติดลบเพราะระบบเดิมไม่แจ้งเตือนข้อผิดพลาดทันทีขณะบันทึก
3. สับสนระหว่างสินค้าที่จับต้องได้กับไฟล์ดิจิทัลที่มีวิธีการจัดการยอดสต็อกต่างกัน

## สิ่งที่ต้องการจากระบบใหม่:
1. ฟอร์มเพิ่มสินค้า (Add Product) ที่มี Floating Labels ชัดเจน และมี Radio Button ให้เลือกชนิดสินค้าตั้งแต่ต้น
2. ปุ่มบันทึกขนาดใหญ่ ชัดเจน พร้อมข้อความแจ้งเตือนสถานะสำเร็จ (Toast Alert) ทันทีหลังกด

---

## Journey Map แบบย่อ: การบันทึกสินค้าเข้าคลังหนึ่งรายการ

| ขั้น | ผู้ใช้ทำอะไร | รู้สึกอย่างไร | จุดสะดุด |
|---|---|---|---|
| 1. เปิดระบบ | ล็อกอินเข้าสู่ระบบด้วย Username/Password | ปกติ | จำรหัสผ่านยากถ้าไม่มีข้อความช่วยเหลือ |
| 2. หาเมนูที่ใช้บันทึก | มองหาปุ่มเพิ่มสินค้าใหม่จากหน้า Dashboard | กังวลเล็กน้อย | ถ้าเมนูซ่อนอยู่ในแถบย่อยจะหาไม่เจอ |
| 3. กรอกข้อมูลสินค้า | พิมพ์ชื่อสินค้า เลือกว่าเป็นสินค้าจริง/ดิจิทัล ใส่จำนวนและราคา | รีบ กลัวกรอกผิดช่อง | **ช่องกรอกไม่มี Label ค้างไว้ พอเริ่มพิมพ์แล้วลืมว่าช่องไหนคืออะไร** |
| 4. กดบันทึก | เลื่อนลงมากดปุ่มบันทึกสีน้ำเงิน | ลุ้นว่าจะผ่านไหม | ปุ่มกดยากถ้าขนาดเล็กเกินไป |
| 5. ตรวจว่าบันทึกสำเร็จ | ดูว่าข้อมูลขึ้นในตารางสต็อกหรือยัง | สบายใจเมื่อเห็นการแจ้งเตือน | ถ้าไม่มี Success Message จะไม่แน่ใจว่าบันทึกสำเร็จหรือยัง |

**จุดสะดุดที่ UI Mockup ต้องแก้ให้ได้:**
> *เพิ่ม Persistent Floating Label เหนือช่องกรอกข้อมูลทุกช่อง และกำหนดสีปุ่ม Primary พร้อมแสดง Toast แจ้งเตือนสถานะสำเร็จในหน้า Add Product*
